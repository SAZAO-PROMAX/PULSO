# Frontend PULSO
Expo 57/React Native/TypeScript estrito. Instalar com npm.cmd ci e abrir com npm.cmd run web. Histórico, gráficos e dashboard partilham LocalRepository (localStorage por perfil). Forms implementa revisão de PDF e tensão; PDF exige API local na porta 8000. A versão nativa informa a limitação do seletor de ficheiros. Ver ../../docs/GUIA_WINDOWS.md para limites e testes.
