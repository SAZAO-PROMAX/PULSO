# Verificações
Executar `node --test tests/foundation.test.mjs` na raiz. Verifica estrutura, marcação fictícia, relações de proprietário e integridade básica dos exemplos. Não testa uma aplicação, API, segurança em execução ou conformidade clínica.
Testes adicionais já existem em services/api/tests, apps/mobile/tests e apps/mobile/e2e. Comandos, distinção entre inferência simulada/real e resultados executados em ../docs/LOCAL_EXTRACTION.md. Testes de navegador usam uma base temporária e exigem portas livres; nunca reutilizam a API normal.
