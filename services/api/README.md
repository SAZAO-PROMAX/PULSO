# API PULSO
FastAPI/Pydantic com /health, /docs e extração determinística de PDF sintético via /demo/extract. /demo/sample.pdf disponibiliza o modelo de teste. PyMuPDF com processo isolado e prazo/limites, sem OCR/LLM. Não guarda documentos ou resultados: a persistência demonstrativa é no navegador. Seguir ../../docs/GUIA_WINDOWS.md para instalação e arranque. Apenas loopback e dados fictícios.
